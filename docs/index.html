    北京市应急管理局 · 预警信息

      北京「预警信息」栏目把每一次空气重污染预警的发布/启动/解除挂在同一列表，标题写的是实际生效时刻。 德州按京津冀联防联控启动/解除，因此把北京的公告与本次响应做时间重叠比对：北京先解除时德州解除临近， 北京仍在响应时德州很少单独解除。
